# Kiara — Format

Sei formati, tre assi: **cosa compri** (Drop), **chi è** (Voce, Ritual), **dove vive
e con chi** (World, Muse, Duet).

| Format | Ruolo | Vende? |
|---|---|---|
| **Drop** | il prodotto — converte | sì, diretto |
| Voce | il pensiero — costruisce carattere | no |
| Ritual | il quotidiano — costruisce intimità | no |
| World | il mondo — costruisce l'universo estetico | no |
| Muse | l'editoriale — alza la percezione premium | no |
| Duet | la collaborazione — monetizza senza spiegare la natura digitale | sì, indiretto |

Non tutti i formati ogni settimana. Il nucleo è **Drop + Voce + World**, gli altri
entrano a cadenza.

## Sequenza editoriale

Prima il desiderio, poi la conversione: almeno 3 contenuti di mondo/voce senza
vendita diretta, poi il quarto con CTA in caption (non aggressiva, nata da una
storia reale).

```
World (desiderio) → Voce (carattere) → Ritual (intimità) → Drop + CTA (conversione)
```

## Calendario settimanale (schema)

| Giorno | Format | Ruolo |
|---|---|---|
| Lunedì | World | costruisce desiderio — atmosfera pura, nessun prodotto |
| Mercoledì | Voce / Ritual (alternati per settimana pari/dispari) | costruisce carattere e intimità |
| Venerdì | Drop (se release attiva) altrimenti Muse | converte o mantiene percezione premium |
| Domenica (opz.) | Duet | monetizza — solo per collab attive |

Frequenza: minimo 3 post/settimana, ottimale 4 — da confermare con volume di
produzione reale.

## Regole

- Mai due Drop nella stessa settimana
- Mai tre post dello stesso format di fila
- Venerdì è sempre il giorno di conversione
